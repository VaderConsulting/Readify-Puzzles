# Readify Puzzles

VB.NET class library with a Readify-style coding puzzle: `Puzzle1.ElementFromLinkedList` returns the nth item from the end of a `LinkedList(Of Int32)`. TestProject is an MSTest shell with an empty `Testpuzzle1` method. Earlier than the C# Readify folder (2013); this is the 2011 VS 2010 attempt.

**Source last updated:** 2011-10-27  
**Language:** VB.NET  
**Target:** .NET 3.5 (Puzzles) / .NET 4.0 (TestProject)  
**Output:** class library + MSTest project

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Puzzles` | VB.NET | class library (.NET 3.5) | `Puzzle1` nth-from-end of a LinkedList |
| `TestProject` | VB.NET | MSTest library (.NET 4.0) | Empty unit-test stub for Puzzle1 |

## How to open

Open `Readify Puzzles.sln` in Visual Studio 2010 or later.
